# Release Notes v4.2.1

Data de lançamento: 20/09/2026

## 🆕 Resumo

Versão de manutenção, sem alteração de comportamento nos pacotes: atualiza as dependências (OpenTelemetry 1.19, EF Core e handlers de autenticação nas linhas 8.0.31 e 10.0.12, `Microsoft.Extensions.*` 10.0.12), passa a publicar **símbolos** (`.snupkg` com SourceLink) e liga a **validação da API pública** no `dotnet pack`. Acompanha a revisão da infraestrutura do repositório: o workflow de release publica no NuGet antes de criar a tag, o CI verifica formatação, pares de pins e cobertura, e a suíte de testes migra para o Microsoft.Testing.Platform com o xunit.v3 4.x. Não há breaking changes.

---

## Modificado

- **Dependências** (todos os pacotes afetados recebem a versão transitiva nova):
  - `OpenTelemetry.*` 1.17.0 → 1.19.0 e `OpenTelemetry.Instrumentation.Process` 1.17.0-rc.1 → 1.19.0-rc.1 (`Tooark.Observability`);
  - `Microsoft.AspNetCore.Authentication.JwtBearer` e `OpenIdConnect` 8.0.30 → 8.0.31 e 10.0.11 → 10.0.12 (`Tooark.Securities`, `Tooark.Securities.OpenId`);
  - `Microsoft.EntityFrameworkCore` 8.0.30 → 8.0.31 e 10.0.11 → 10.0.12 (`Tooark.Mediator.EntityFrameworkCore`);
  - `Microsoft.Extensions.Localization` 8.0.30 → 8.0.31 e `Microsoft.Extensions.*` 10.0.11 → 10.0.12 (`Tooark.Extensions`, `Tooark.Mediator`, `Tooark.Mediator.EntityFrameworkCore`);
  - `Microsoft.AspNetCore.Http` 2.3.12 → 2.3.13 (`Tooark.Utils`).
- **Símbolos e SourceLink** — o build `Release` passa a gerar PDB portátil, publicado no `.snupkg` ao lado de cada `.nupkg`. Até a v4.2.0 o `DebugType` era `none`, então o SourceLink declarado não tinha efeito e não era possível depurar dentro do código do Tooark a partir de uma aplicação consumidora.
- **Validação da API pública** — `EnablePackageValidation` com baseline na v4.2.0: uma quebra acidental de compatibilidade (membro removido, assinatura alterada, TFM a menos) passa a falhar o `dotnet pack`.
- **Metadados dos pacotes** — `Copyright` e `PackageReleaseNotes` (link para o arquivo em `Notes/`) preenchidos no nuspec.

## Corrigido

- `Tooark.Securities`, `Tooark.Extensions`, `Tooark.Observability`, `Tooark.Validations`, `Tooark.ValueObjects` — arquivos com BOM, espaço em branco no fim de linha ou sem quebra de linha final, fora do `.editorconfig`. Só formatação; nenhum código muda.

## Infraestrutura do repositório

- **Release** (`tooark.yml`): os pacotes são publicados no NuGet (com `--skip-duplicate`) **antes** de a tag e a GitHub Release existirem; uma publicação interrompida no meio não deixa mais uma tag órfã que bloqueava a reexecução. A release é criada pelo `gh release create`. Os testes rodam em `Release`, o token recebe só as permissões necessárias (`contents: write` para a tag, `packages: read` para a imagem do scanner) e a checagem duplicada de tag foi removida.
- **CI** (`ci.yml`): passa a verificar `dotnet format --verify-no-changes` (`.editorconfig`), os pares de pins do runtime (`scripts/check-package-pairs.sh`) e a cobertura (relatório Cobertura como artefato e resumo no job). O job `build-and-test` é status check obrigatório no ruleset da `main`.
- **Dependabot**: os pacotes atrelados ao runtime (`Microsoft.AspNetCore.Authentication.*`, `Microsoft.Extensions.*`, `Microsoft.EntityFrameworkCore*`, `System.Security.Cryptography.Xml`) deixam de ser atualizados por ele, que só enxergava o grupo `net8.0` e deixava o `net10.0` para trás (PR #54); a atualização é manual, em pares. O ferramental de teste (`xunit*`, `coverlet*`, `Microsoft.Testing.*`, `Microsoft.NET.Test.Sdk`) sobe junto num grupo próprio, incluindo majors.
- **Testes**: `xunit.v3` 3.2.2 → 4.0.1 e `xunit.runner.visualstudio` 3.1.5 → 4.0.0, com a suíte executada pelo **Microsoft.Testing.Platform** (`UseMicrosoftTestingPlatformRunner` no projeto e `test.runner` no `global.json`), já que o modo VSTest do `dotnet test` deixou de ser suportado pelo MTP no SDK 10. A cobertura passa do `coverlet.msbuild` (só VSTest) para o `coverlet.MTP`. Os comandos de execução, filtro e cobertura mudam; os READMEs raiz e do `Tooark.Tests` foram atualizados.
- **Build**: `EnforceCodeStyleInBuild` liga as regras de estilo do `.editorconfig` com severidade `warning` (namespace file-scoped, `using` fora do namespace) no build.
- **Documentação**: dúvidas passam a ir para as Discussions (Q&A) em vez de issue em branco; `CONTRIBUTING.md` lista o `Tooark.Dtos` entre os pacotes que declaram o framework compartilhado e explica o `Microsoft.AspNetCore.Http` 2.x do `Tooark.Utils`; READMEs do `Tooark.AspNetCore`, `Tooark.Utils` e `Tooark.Observability` (dependência pré-lançamento) ajustados; `.gitattributes`, `.vscode`, `scripts/` e `LICENSE` corrigidos.

## Impacto

- Compatível: nenhuma API pública muda. Consumidores recebem as dependências transitivas atualizadas e passam a ter símbolos disponíveis no NuGet (`.snupkg`).
- Contribuidores: os comandos de teste mudam para o modo MTP (`dotnet test --project ...`, filtros `--filter-namespace`/`--filter-method`, cobertura com `--coverlet`). Veja o README raiz e o `Tooark.Tests/README.md`.
- Compatível com .NET 8.0+ e .NET 10.0+.
